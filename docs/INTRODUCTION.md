# 声之轨是什么？

声之轨是一个放在 Mac 菜单栏里的声音控制工具。它把系统总音量、每个应用的音量和播放设备放在一个面板里，让你决定哪些声音更响、哪些静音，以及它们从哪里播放。

它只驻留顶部菜单栏，不显示 Dock 图标，不会在启动时打开独立窗口。它不会改写苹果自带的“声音”面板，也不需要安装第三方虚拟音频驱动。

## 为什么做它

我们最初遇到的问题是：Mac 上正在播放视频，微信电话一进来，其他声音就被自动压低了。用户即使想同时听视频和通话，也缺少直观的调节方式。

声之轨支持分别调整应用的音量和输出设备。旧版通话音量保护已因恢复后无声的问题移除。

## 可以怎么用

| 场景 | 操作方式 |
| --- | --- |
| 微信通话时继续看浏览器视频 | 开启浏览器的音频控制，按需要调整视频音量；系统通话压低仍可能生效 |
| 音乐太响，通话声音太小 | 分别开启音乐和通话应用的控制，独立调整音量 |
| 希望某个应用使用耳机 | 连接耳机，在该应用的“输出到”中选择耳机 |
| 希望某个应用始终跟随系统设备 | 将该应用的“输出到”设为“跟随系统输出” |
| 想恢复系统原来的播放方式 | 关闭对应应用的开关，或点击“恢复所有应用” |

每个应用的独立输出能力仍取决于设备和系统兼容性；上表描述的是功能用法，不代表所有设备组合都已验证。

## 第一次使用

1. 打开声之轨，点击菜单栏里的扬声器图标。
2. 在上方选择系统输出设备，或调整系统总音量。
3. 展开“应用音量”，找到要控制的软件，打开它右侧的开关。
4. 如果 macOS 弹出系统音频录制提示，允许声之轨访问应用输出音频。
5. 调整该应用的音量、静音或播放设备。

应用列表会自动更新。蓝色开关表示声之轨正在接管这个应用的声音，灰色表示它继续使用系统原来的播放方式。

**应用开关不是静音按钮。** 要让一个应用暂时无声，请使用音量条左边的扬声器按钮。关闭窗口只会收起面板；点击“退出”才会关闭声之轨。重新启动后，需要手动开启应用控制，已保存的音量和设备选择会保留。

## 通话期间的音量

旧版通话音量保护会通过未公开的系统属性影响其他应用，导致关闭独立控制后无声，现已移除。当前不承诺阻止系统或通话软件压低声音。蓝牙耳机进入通话模式造成的音质变化也需要另行处理。

## 为什么需要“音频录制”权限

为了独立调整音量和输出，声之轨需要先取得目标应用正在输出的声音，再在本机处理和播放。系统把这类访问归入音频录制权限。

当前实现不保存音频文件、不上传声音、不读取屏幕画面，也不采集麦克风。仅打开面板或切换系统输出不会触发这项授权；首次开启应用音频控制时才会请求。

## 现在适合谁使用

目前是早期原型，适合愿意从源码构建、反馈兼容性问题的 Mac 用户和开发者。主要验证环境是 Apple Silicon、macOS 26.4；项目最低系统要求是 macOS 14.2，构建需要 Swift 6 工具链。

开启控制后会增加处理路径和延迟，因此它不属于完全无损直通或专业监听设备。内部信号测试已覆盖高频幅度、声道隔离和采样率转换等项目，但没有替代对具体扬声器、耳机和长时间播放的实测。
