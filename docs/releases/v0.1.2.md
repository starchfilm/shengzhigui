### 正式应用图标

- 采用已选定的轻玻璃图标：乳白磨砂底座、半透明蓝色声波路径与细边缘折光。
- 应用图标包含 16–1024 像素多种尺寸，用于 Finder、应用程序目录和安装包中的应用。
- 菜单栏继续保留清晰的单色扬声器图标；应用只驻留顶部，不显示 Dock 运行图标。
- 音频处理逻辑保持不变。

### 安装与更新

下载 **ShengZhiGui-0.1.2-universal.dmg**，将“声之轨.app”拖入 Applications。更新前先从旧版面板退出，再替换应用文件。

要求 macOS 14.2 或更新版本，包含 Apple Silicon 和 Intel 架构；Intel 尚未实机验证。此版本仍为临时签名、未经苹果公证的公开测试版，首次打开或更新后可能需要重新确认系统权限，详见 [苹果说明](https://support.apple.com/102445)。

通话音量保护只对开启控制的应用生效，并依赖系统兼容接口。权限、隐私和音频测试边界见 README 与音频验证记录。
