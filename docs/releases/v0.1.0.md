声之轨首个公开测试版：在 Mac 菜单栏中独立控制每个应用的音量和输出设备。

### 下载与安装

下载下方的 **ShengZhiGui-0.1.0-universal.dmg**，打开后将“声之轨.app”拖到 **Applications**，再从“应用程序”打开。

- 系统要求：macOS 14.2 或更新版本。
- 包含 Apple Silicon（arm64）和 Intel（x86_64）架构；主要实测环境是 Apple Silicon、macOS 26.4，Intel 尚未实机验证。
- **这是临时签名、未经 Apple 公证的测试版。** macOS 可能阻止首次打开。请确认下载来自本仓库，并参考 [苹果的应用打开说明](https://support.apple.com/102445)。本项目不会要求你关闭系统整体安全保护。
- 同时提供 `.sha256` 文件，可在下载目录运行 `shasum -a 256 -c ShengZhiGui-0.1.0-universal.dmg.sha256` 核对完整性。

### 主要功能

- 调节系统总音量，切换系统播放设备。
- 展开应用列表，分别调节音量、静音和输出设备。
- 对已开启控制的应用启用通话音量保护。
- 保存应用音量与设备选择，支持恢复系统原始播放路径。
- 音量滑条失焦后保持蓝色，通道状态文字保持稳定。

### 权限与限制

首次开启应用音频控制时，macOS 会请求系统音频录制权限。声音只在本机处理，不保存或上传，不采集麦克风或屏幕图像。

通话音量保护只对开启了控制开关的应用生效，并依赖未公开的系统兼容接口。蓝牙通话模式导致的音质变化、长时间播放、睡眠唤醒和不同设备组合仍需扩大验证。启用控制会增加处理延迟，不是完全无损直通。

发布流程会先运行 8 项音频处理测试，再构建并校验 DMG。详见仓库中的 [产品介绍](https://github.com/starchfilm/shengzhigui/blob/main/docs/INTRODUCTION.md) 和 [音频验证记录](https://github.com/starchfilm/shengzhigui/blob/main/docs/AUDIO_VALIDATION.md)。

遇到问题请在 Issues 中提供系统版本、芯片、设备型号和复现步骤，无需上传私人通话录音。
